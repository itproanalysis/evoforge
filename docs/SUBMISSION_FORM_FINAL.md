## Short description
EvoForge is a coding workspace that turns a goal into a tested, replayable result. Muse Spark
builds, GPT and Gemini plan, an independent Claude Critic writes tests from the specification,
and a remote Runner evaluates the code. Inspect both lanes, model costs and a signed proof.
No API key entry is required to try the current server-funded configuration.

## How it works and Meta technology
Muse Spark1.3 is the principal Builder through Meta Model API and remains the single-call
comparison model. The system adds GPT-6.1 Sol and Gemini4 Argon implementation plans plus
Claude Opus5.5 specification-first Critic feedback. The Critic is isolated from planner advice.
Each model call reserves an integer-cent budget before dispatch; known usage settles it,
uncertain charges stay held for reconciliation. Next.js and FastAPI run on Cloud Run; a
separate Runner executes candidate code; PostgreSQL stores scoped state; Ed25519 signs
result certificates. Existing authorization and integrity gates control PR promotion.

## Known limitations
One shared project and a site-wide20-run daily quota; no per-user account isolation.
Usage-based model costs are not provider invoice reconciliation and omit Runner compute.
A signature authenticates result bytes; it cannot establish verifier safety against malicious
candidate code. Runner metadata egress and candidate-resistant report isolation remain hardening
work. We do not claim general superiority or a statistically significant multi-model gain.
