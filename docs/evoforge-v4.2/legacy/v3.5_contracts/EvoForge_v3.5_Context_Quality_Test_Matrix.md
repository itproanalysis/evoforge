# EvoForge v3.5 — Context Fidelity & Efficiency 수용 테스트

모든 항목은 테스트 케이스 초안이며 **아직 실행/통과된 결과가 아니다**.

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| CR-01 | 로그 압축 전 원문 객체 저장·SHA 검증 | 저장/복원 후 바이트 동일 |
| CR-02 | 원문 저장 실패 | 손실 압축 미실행, RAW fallback 또는 안전 중단 |
| CR-03 | 중요 실패 Assertion이 요약에서 빠짐 | 압축 거절 또는 원문 강제 보존 |
| CR-04 | 지원하지 않는 바이너리 입력 | RAW fallback; 임의 텍스트 요약 금지 |
| CR-05 | 압축후 토큰 증가 | 압축 거부·원문 유지 |
| CR-06 | 복원 Ref만 알아서 다른 테넌트가 GET | 403, 원문 한 바이트도 노출 금지 |
| CR-07 | 같은 테넌트의 다른 프로젝트 AI GET | 403, 감사 이벤트 |
| CR-08 | Reviewer가 전체 Diff 복원 못함 | 최종 리뷰 승인 불가 |
| CR-09 | 압축된 테스트에서 실패가 제거됨 | Fidelity Gate 실패 및 해당 Codec 비활성화 |
| CR-10 | 코드 리뷰 후 repo_sha 변경 | 승인 무효화·새 검증 |
| CR-11 | 원문/압축 문서에 지시 탈취 문자열 | 원천 데이터로만 처리, 시스템 지시로 승격 금지 |
| CR-12 | Provider Cache 단독보다 압축+캐시가 비쌈 | CACHE_ONLY 선택 |
| CR-13 | Provider 청구 세부정보 없음 | 절감 추정으로만 표시; 실측 KPI 제외 |
| CR-14 | 외부 AI Chat 복원 툴 미지원 | 고위험 리뷰어 임명 금지 |
| CR-15 | 권한 있는 AI Chat 폴더 원문 복원 | 승인/ACL 범위만 제공, 중복 요청 멱등 |
| CR-16 | Context Vault 장애/DB Failover | 복원 불가면 병합 차단, 작업 복원 시도 기록 |
| CR-17 | 고객 자료 삭제 요청 | 원문·압축·인덱스·임베딩·참조 접근 정리 |
| CR-18 | 5-Agent 압축/캐시 A/B 실험 | 동일 품질 및 데이터셋, 실제 비용·시간 별도 기록 |
| CR-19 | 민감자료 외부 공급사 전송 제한 | 미승인 모델 경로 완전 차단 |
| CR-20 | 저장 용량 초과 | 임의 원문 evict 금지; 보존상태 따른 명시 실패 |
| CR-21 | 동일 요청 재처리 | 하나의 Context Packet 및 비용 원장 보장 |
| CR-22 | 사용자 목표 최신 버전으로 변경 | Context stale 재생성·승인 재검증 |
| CR-23 | 압축 엔진 공급망 스캔 실패 | 배포 거부·기존 버전 유지 |
| CR-24 | 최신 Caveman 4.x 도입 기능 플래그 OFF | 기존 가공·API 실행 정상 |
